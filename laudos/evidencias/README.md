# Evidências dos testes

Coloque aqui os prints de tela e os trechos de log coletados durante os testes
com os colegas.

**Convenção de nome:** `<id-da-ocorrencia>-<descricao-curta>.png`

Exemplos:

```
e01-listagem-lenta-antes.png
e01-listagem-rapida-depois.png
e02-filtro-periodo-erro.png
e03-anexo-acima-do-limite.png
e04-descricao-em-branco.png
e05-mensagem-fora-da-tela-celular.png
```

Sempre que possível, guarde o par **antes** e **depois** — é a prova mais
direta de que a correção funcionou.
