# Evidências dos testes

Prints de tela e trechos de log coletados durante os testes com os cinco
testadores, e as telas correspondentes depois da correção.

**Convenção de nome:** `<id-da-ocorrencia>-<descricao-curta>.png`

Exemplos:

```
l01-botao-travado-anexo-grande.png
l02-filtros-ocupando-a-tela-celular.png
l03-403-sem-caminho-para-o-painel.png
l04-encerramento-sem-justificativa.png
l05-erro-so-no-topo.png
l06-listagem-quebrada-apos-cancelar.png
```

Sempre que possível, guarde o par **antes** e **depois** — é a prova mais
direta de que a correção funcionou. O mapa completo de cada ocorrência está em
[`docs/validacao-laudos.md`](../../docs/validacao-laudos.md), e o resumo dos
laudos em [`../README.md`](../README.md).

Os prints que os testadores colaram no campo 7 ficam nos próprios `.docx`, na
pasta acima.
